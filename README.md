## “静态”有三种含义，价格差的第一个来源就在这里

报价单上写“静态住宅”，实际可能是三种完全不同的东西。

第一种是**真家宽**：在真实民宅拉当地运营商光纤，ASN 属于 AT&T、Comcast、Frontier、NTT 这类民用宽带运营商，IP 长期固定。成本最高，扩容要等下一批房子装好线，所以这类产品经常售罄。

第二种是**长效静态**：IP 确实固定，但线路落在机房或城域网，ASN 可能是数据中心或城域网出口。不少平台照样把它标成“静态住宅”，价格能压到几元一个月。

第三种是**会话保持（Sticky Session）**：底层仍是动态池，只是在你设定的时长内保持同一个出口，到期就换。它最便宜，也最不适合长期登录态。

还有一层容易被忽略。某海外 ISP 代理服务商的官方 FAQ 写得很直白：ISP 代理托管在数据中心，只是与提供住宅 IP 的 ISP 合作使用其 ASN。所以 **ASN 是 ISP，只说明它过了第一关**，不代表这条线真的从某户人家的光猫里接出来。第三方 IP 数据库如果把这个段标成 hosting，用该库做判断的下游风控系统照样会把它当机房 IP 处理。

## 价格从 2 元到 800 元，差在四个地方

**独享还是共享。** 独享 IP 只归你一个人用，成本最高。共享或半独享便宜，代价是邻居违规你连坐：同一条 IP 上有人刷单、发垃圾信息，账号被关联封禁时你连申诉理由都说不清。这是价格差异最主要的一项。

**地理位置与 ISP。** 美国和日本这类需求量大的地区，住宅资源相对充足，价格反而适中。北欧、非洲等冷门地区资源难拿，单价更高。AT&T、Comcast 这类信誉好的本土 ISP 段，报价通常也比小运营商高一档。

**资源稀缺程度。** 一条真实家宽能分出来的静态 IPv4 极少，扩容要真装机。所以静态住宅 IP 的月价普遍是同带宽机房 IP 的 2–5 倍，贵在资源，带宽成本占比很小。

**购买数量与计费周期。** 一次买 10 条以上通常有折扣，海外平台常见 5–9 条 2%、10–49 条 5%、50–199 条 10%、200–499 条 20% 的分档。年付也比月付便宜，但幅度因品牌而异：有的平台对外称年付比月付低 20%–40%，也有厂商明确写半年付 9 折、年付 8 折。不要把某一家品牌的折扣当成行业标准。

## 四步验真：把测试 IP 跑一遍再付钱

这套方法不需要任何特殊工具，四步全过再下单。

**第 1 步，查 ASN 归属。** 用 ipinfo.io 或 bgp.he.net 查测试 IP，看 ASN owner 是民用宽带运营商还是云厂商、IDC。这一步一票否决：ASN 属 IDC 的，后面三步不用做了。商家不给测试 IP、只给“演示截图”的，直接跳过。

**第 2 步，查第三方 IP 类型库。** ipapi.is 或 ip-api.com 看 type 字段，IP2Location 看 usage type，Scamalytics 看 fraud score。判定标准是三个库里至少两个标 residential 或 ISP，且 fraud score 低于 25。某个库标 hosting，说明这个段被它收录为机房，用在它的下游风控系统里仍会被识别。

**第 3 步，查黑名单与滥用记录。** AbuseIPDB 看举报次数和最近举报时间，Spamhaus ZEN、SpamCop 等主流 DNSBL 看是否被列入。近 90 天无举报、黑名单零命中才算干净。IP 出身真不等于 IP 干净：一条真家宽 IP 如果上一个用户拿它刷过单，你接手就是脏 IP。买之前问清楚能不能指定“未被使用过的新 IP”。

**第 4 步，查 DNS、WebRTC 泄漏与时区一致性。** 浏览器打开 browserleaks.com/webrtc 和 ipleak.net，DNS 解析地、WebRTC 暴露的出口、系统时区和语言，三项都要和 IP 归属地一致。

判定卡可以直接存下来：

- 第 1 步 ASN = ISP（非 hosting），一票否决
- 第 2 步 三个类型库至少两个标 residential 或 ISP
- 第 3 步 黑名单零命中、90 天内无举报
- 第 4 步 DNS/WebRTC 不泄漏、时区语言一致

四步全过，可以用于养号；缺任意一条，这条 IP 只适合采集。

## 按场景选：养号、电商、采集、流媒体、游戏

**TikTok 与社媒养号**看四件事：ASN 是 ISP、租期内 IP 不变、独享、时区一致。选静态住宅独享档，一条 IP 长期持有，别为了省钱几个人挤一条线。

**电商多账号**（亚马逊、独立站、eBay）要求一号一 IP 且互不关联。除了独享，还要分散到不同运营商和不同 C 段，同一 C 段挂多个店铺容易被判关联。

**数据采集与 SERP 监控**看 IP 池规模和轮换策略，动态住宅或住宅池按流量计费更划算，不追求长期固定。

**流媒体解锁**看出口地区准确率和实测带宽，按需短租即可，不必年付。

**游戏多开**看延迟、丢包和是否支持 UDP 转发，SOCKS5 线路不支持 UDP 时，游戏内语音和对战会出问题。

**长期登录态维护**（AI 平台等）看 ASN、黑名单记录和长期稳定性，静态住宅长租更省。

地区只由账号注册地决定，不是哪里便宜买哪里。美国优先 AT&T、Comcast、Frontier 这类本土民用段；日本以 NTT、SoftBank、KDDI 为主，注意区分“东京机房”和“东京家宽”；香港住宅 IP 资源少、单价普遍更高，IDC 伪装也多，必须查 ASN；韩国优先 KT、SK Broadband、LG U+；欧洲按具体国家选，时区和语言要跟着对齐。

宣称覆盖“160+ 国家”“180+ 国家”的平台，各国住宅库存差异极大，热门国家现货多，冷门国家多为机房或需要预订。下单前问清楚你要的那个国家、那个城市是现货住宅还是机房或预订，比看总覆盖数有用。

## 五个坑和五个配置错误

**坑 1：商品名里有“住宅”，ASN 却不是 ISP。** 最常见的是机房 IP 套一层家宽包装。检查方法只有一个：先要测试 IP，跑第 1 步查 ASN。

**坑 2：“独享”被偷换成“独享线路”。** 独享 IP 指这条 IP 只给你用；独享线路只说明带宽不与人分享，IP 可能仍在共享段。下单前明确问：同一 IP 同时段有没有其他用户。

**坑 3：流量单向还是双向没问。** 标 2000GB 的套餐，双向计费时上传也扣。买之前问一句计费方向，重度使用差一倍。

**坑 4：预订等待期不退款。** 付款后排队交付，等待期内通常不退，到期从开通日算。付款页确认交付时间和退款条件。

**坑 5：出口 IP 与宣称地区不符。** 宣称“美国加州住宅”，实际落在别的州甚至别的国家，低价海外档里不罕见。多买 3–5 条不同节点逐条查归属地，第一条不符就要求换。

配置层还有五个常见错误：只改 IP 没改时区和语言；DNS 没走代理，泄漏真实位置；WebRTC 暴露真实出口；代理设成全局导致本地服务全断；一条 IP 同时登多个账号，以为“IP 干净就行”。

最后一条要单独说：任何平台都不保证 IP 永久可用。静态住宅的“静态”指地址不变，不指永不被封。

**静态住宅 IP 一般多少钱？**

**续费会涨吗，能保留原 IP 吗？**

现货通常即时到数小时，预订可能几天到两周。到期时间一般从实际开通日算，不从付款日算。
